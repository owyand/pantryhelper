\# Pantry Helper



\## Problem (1 sentence)

I have a hard time keeping track of what groceries I have and need as well as what groceries are still viable.

\## What I'm building (2-3 sentences)

A smart database for inventory control with a touch UI for manual CRUD operations

\## Why I'm building it (learning goals)

For fun - It is useful and something that i will use. I want to have a complete project to showcase which encompasses both software and hardware.

\## Success looks like

Scanning a barcode adds an item (or increments its quantity) in under 3 seconds.

Scanning an item already in the database offers add / remove, and removal updates the count.

The UI lists all items sorted by expiry date, with expired items visibly flagged.

The data survives a power cycle.

Barcode lookup falls back to manual name entry when the product isn’t found.

\## Non-goals

No mobile development

No fancy UI

No AI integration

No notifications

No user profiles
