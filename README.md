# pantryhelper
## Problem statement
Food waste is bad for the economy, planet, and your budget. This project aims to reduce individual food waste by tracking pantry items, recommending meals from current provisions, and notifying of soon expiring products.

## What I'm building
At its core, it is a database for inventory control with a touch UI and barcode scanning CRUD operations. Additionally, it will be able to suggest meals based on what is currently available and it will notify when things are expired or soon expiring. Having a hosted database will eventually allow for users to remotely check what is in their kitchen when at the store or to auto add items to a usual shopping trip. 

## Why I'm building it
This is a concept I have had in mind for awhile and it is something that I have received much encouragement from others to create because they would use it. I want to have a showcase project which encompasses both hardware and software and which can be continually expanded upon. Eventually, I want to host the database somewhere else on my LAN and protect the network traffic.
